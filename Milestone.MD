Treis Adiutor accepts three forms of payment

1. Full Payment
2. Milestone Payment
3. Downpayment

For full payment, all tasks and documents are ALREADY UNLOCKED AND ACCESSIBLE TO CLIENT ANY TIME, AS LONG AS THE ADIUTOR HAS SUBMITTED THEM ALREADY.
For MILESTONE PAYMENT, tasks / documents ARE LOCKED AND ONLY ACCESSIBLE TO CLIENT IF THE PAYMENT HAS BEEN MADE FOR THE PHASE THE TASK IS ASSOCIATED.
FOr downpayment, tassks / documents are only accessible to client if the remaining balance has been made for the whole project.

Notes: When we say documents, it is not limited to word docx, pdf, etc. It can also be links, repositories, images, etc. Documents = output.

Current Process:
1. Client submits a request
2. Admin approved the request with an approved budget.
3. Client pays the whole amount.
4. Request turns into a project.
5. Admin can now assign team members for projects, create tasks, and so on.
6. Adiutor delivers documents 
7. Client can view it.

What it should be:
1. Client submits a request
2. Admin approved the request with an approved budget, select form of payment (full payment, milestone payment, downpayment).
3. If Full payment, client pays whole amount.
If milestone payment, admin defines how many phases. Then based on number of phases, can set a percentage for each phases. Then, the first payment of client should be FULL AMOUNT X CURRENT PHASES PERCENTAGE (EXAMPLE: 100,000 X 30% (PHASE 1)). This payment can be made for every milestone. But, phase 1 requires initial payment. Succeeding or next phases can be made one phases are done. (EXAMPLE, TO START A PROJECT, CLIENT NEEDS TO PAY PHASE 1. BUT NEXT PHASES CAN BE PAID NEXT WHEN THAT PHASES ARE ONLY DONE. PHASE 1 PAYMENT ARE REQUIRED BECAUSE REQUEST CAN ONLY BECOME A PROJECT ONCE CLIENT PAID)
Downpayment, admin defines how much percentage for downpayment. Then client pays that downpayment. Documents are accessible to the client ONCE THEY PAY FOR THE REMAINING BALANCE.
4. Request turns into a project.
5. Admin can now assign team members for projects, create tasks, and so on.
6. Adiutor delivers documents 
7. Client can view it.


Note: Phases refers to predefined admin phases upon milestone project. These phases can consist of multiple tasks (for example, when creating a task, admin can define which phase it includes. But, for intuitiveness, it should be automatically the current phase.).
